Download dos Dados

Todos os dados processados estão disponíveis para download em formato Apache Parquet (compressão zstd).

Podem ser lidos com DuckDB, Polars, Pandas, Spark, ou qualquer ferramenta que suporte Parquet.

Exemplo rápido (DuckDB)

-- Instale: pip install duckdb
-- No Python:
import duckdb
duckdb.sql("SELECT * FROM 'fact_enade.parquet' WHERE co_ies = 87").show()

-- Ou no CLI:
-- duckdb -c "SELECT * FROM 'fact_igc.parquet' LIMIT 10"
